# Angkringan East Corner

Landing page statis untuk Angkringan East Corner: satu halaman berisi header, tentang kami, menu, dan kontak.

## Isi

- `index.html` - markup halaman
- `css/style.css` - tata letak dan warna
- `js/script.js` - interaksi navigasi
- `img/` - gambar header dan bagian tentang kami

## Menjalankan

Buka `index.html` di browser.

Versi revamp berbasis Next.js ada di [angkringan-east-corner](https://github.com/adhika26/angkringan-east-corner).
